# fullstack_developer_capstone

## Repository Name
**fullstack_developer_capstone**

## Project Name
**Car Dealership Review Application**

## Project Overview
The **Car Dealership Review Application** is a full-stack Django and React web application developed for the IBM Full Stack Application Development Capstone Project. It allows users to browse car dealerships, view dealer details, read reviews, and submit reviews for dealerships. The application includes user registration and authentication, dealer filtering by state, sentiment analysis on review text, and a CI/CD deployment workflow using GitHub Actions.

## Repository
This repository contains the complete capstone project source code:

- `server/` — Django backend and static frontend pages
- `server/frontend/` — React frontend components
- `server/djangoapp/` — Django app APIs and models
- `.github/workflows/` — GitHub Actions CI/CD workflow
- `README.md` — Project documentation

## Main Features
- User sign-up and login/logout
- Dealer listing and dealer detail pages
- Dealer reviews and review submission
- Dealer filtering by state
- Car makes and models API
- Sentiment analysis for review text
- Admin login/logout
- Automated CI/CD workflow
- Public deployment of the Django application
